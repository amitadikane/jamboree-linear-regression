# Jamboree Education — Graduate Admission Prediction (Linear Regression)

**Domain:** Education / EdTech  
**Tools:** Python, Scikit-learn, Matplotlib, Seaborn  
**Focus:** EDA → Linear Regression → Regularization → Assumption Testing

---

## 📌 Problem Statement

Jamboree helps Indian students get into top graduate programs abroad and has launched a feature that estimates a student’s Chance of Admit to Ivy League colleges.

Business questions:
1. Which factors (GRE, TOEFL, University Rating, SOP, LOR, CGPA, Research) most influence admission chances?
2. Can we build a reliable predictive model, and how well does it perform?

---

## 🎯 Project Workflow

1. Exploratory Data Analysis (distributions, correlations, multicollinearity)
2. Build baseline Linear Regression model
3. Compare with Ridge and Lasso regularization
4. Test regression assumptions (linearity, homoscedasticity, normality of residuals, VIF)
5. Evaluate using MAE, MSE, R²
6. Deliver actionable recommendations for Jamboree

---

## 🛠️ Tech Stack

- Python, Pandas, NumPy
- Scikit-learn (LinearRegression, Ridge, Lasso, StandardScaler)
- Matplotlib, Seaborn

---

## 💡 Key Predictors

- CGPA and GRE Score are usually the strongest predictors
- Research experience and LOR/SOP strength also contribute
- Regularization helps stabilize coefficients when multicollinearity is present
